# The Miners Dreams

Forge 1.20.1 mod. Right click a block with a Miners Dream and it blasts a tunnel the way you're looking (up and down too), leaving all the ores in the walls. Based on the Miners Dream from OreSpawn.

Download on [Modrinth](https://modrinth.com/mod/the-miners-dreams) or CurseForge.

![netherite miners dream](https://cdn.modrinth.com/data/CFNZu3Pj/images/8717b568edf95f4286faf0be200a715766d9d6f5.gif)

## Tiers

| Tier | Uses | Tunnel | Dimensions |
|---|---|---|---|
| Miners Dream | 4 | 51 x 11 x 7 | Overworld |
| Iron | 16 | 75 x 11 x 7 | Overworld |
| Gold | 32 | 100 x 13 x 7 | + Nether |
| Diamond | 64 | 150 x 13 x 9 | + End |
| Netherite | infinite | 200 x 15 x 9 | + End |

Craft the base one with 3 cactus, 3 redstone blocks and 3 gunpowder. Upgrade at a smithing table with TNT in the template slot and a block of iron/gold/diamond/netherite.

Also has Reach and Blast Radius enchantments, dispenser support and a config (`config/minersdream-common.toml`).

## Building

```
./gradlew build
./gradlew runGameTestServer
```
